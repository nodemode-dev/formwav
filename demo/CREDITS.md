The demo opens on "Round the Moon, a field report": a launch radio cold open, a reading from Jules Verne, a piano piece and a Saturn plasma-wave bed. Each file below ships as a JavaScript data pack in `demo/assets/media/` (base64 of the mp3), so the page decodes it from `file://` with no fetch. Licences are as stated on each source page, read before download.

Notes

- Source page checks: the archive.org item, the LibriVox page, the NASA sounds page and the NASA guidelines page were opened and read with a web fetch before download. The Commons description page could not be opened by that fetch tool; it was read through the Commons API (`action=query`, wikitext and extended metadata) instead, which returned the PD-author template and the Musopen statement quoted above.
- The recordings are lossy on arrival (mp3 or Vorbis) and are encoded once more, so they are demo audio, not masters.
- The synthetic Dialogue, Music and Drums samples in the Sounds tab are generated by `demo/src/synth.ts` and carry no third-party material.
- Media size: the six packs total about 3.7 MB.
