# Needs Python 3.11 or later. Install PyTorch for your hardware first, so pip does not swap in a build the machine
# cannot run (SAM-Audio also needs torchvision and torchcodec at matching versions):
#   NVIDIA GPU (recommended by Meta): the CUDA build from https://pytorch.org/get-started/locally/
#   macOS (Apple Silicon runs on MPS, slowly): pip install torch torchaudio torchvision
#   CPU only: works, very slowly
# Then:
#   pip install -r requirements_sam_audio.txt
#
# The checkpoints are gated. Request access on the model's Hugging Face page (manual approval), then log in:
#   https://huggingface.co/facebook/sam-audio-small   (5.10 GB, the default)
#   https://huggingface.co/facebook/sam-audio-base    (7.73 GB)
#   https://huggingface.co/facebook/sam-audio-large   (14.86 GB)
#   hf auth login
# Pick one with FORMWAV_SAM_AUDIO_MODEL (for example facebook/sam-audio-base); the first isolation downloads it.
# GET /api/sam-audio/status (and the Effects section) says which of these steps is still missing.
#

# (dacvae, ImageBind, CLAP, perception_models), so installation takes a while.
