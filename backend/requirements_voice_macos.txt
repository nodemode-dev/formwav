# package MEMBERSHIP in sync with requirements.txt.

# The default torch/torchaudio wheels on macOS are MPS-capable — exactly what
# formwave targets on an M-series machine. Do NOT add a CUDA index URL here.

# dependencies are listed explicitly below with transformers pinned to 4.57.6
