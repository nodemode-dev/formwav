# Credits for the repair demo media

The repair demo opens on a real, noisy public-domain recording and offers three more. Two are cut from Wikimedia Commons recordings and ship as JavaScript data packs in `demos/repair/assets/media/` (base64 of an mp3), so the page decodes them from `file://` with no fetch. The other two are read, by path and unchanged, from the packs of the first demo (`demo/assets/media/`), whose rows are in [../../demo/CREDITS.md](../../demo/CREDITS.md) and repeated below. Licences are as stated on each source page, read before download.

Notes

- Source checks: both Commons file pages refuse the shell, so licence and category data were read through the Commons API (`action=query`, `prop=imageinfo`, `iiprop=extmetadata`). The SHA-1 and size the API reports for each file equal the downloaded originals (Caruso 2116093 bytes, 71387436f806daca08b00d5abfcb4ce13b34bb0e; One-Step 1324771 bytes, d9c301d814d913ae0ce8d6986908b6c07637ad61). The archive.org credit page for the One-Step could not be fetched; the Commons record carries the licence. The NASA sounds page was fetched and lists the STS-135 commentary; it points to the NASA media guidelines for use.
- Where each cut sits in its source was found by correlating the pack against the original (correlation 0.9999997 for the One-Step at 108.0 s, 0.99 for Caruso at 8.0 s, the lower figure being the gain and mono mixdown).
- The recordings are lossy on arrival and are encoded once more, so they are demo audio, not masters.
- Media size in this folder: the two packs total about 0.98 MB; the demo also reads two packs from the first demo (about 0.7 MB).
